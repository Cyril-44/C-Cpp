### 对给定区间 $I$ 进行处理

```cpp
vector<int> nodes;
void divide(int u, int ql, int qr, int l, int r) {
    if (ql <= l && r <= qr)
        return void(nodes.push_back(u));
    int mid = (l + r) / 2;
    if (ql <= mid) divide(u<<1, ql, qr, l, mid);
    if (mid < qr) divide(u<<1|1, ql, qr, mid+1, r);
}
```

将目标区间 $I=[l,r]$ 进行线段树分解，如上得到的 `nodes` 记为 $D(I)$。**一个存储方案能覆盖 $I$，当且仅当它能分别覆盖 $D(I)$ 中的每一块。**

这是因为，任何用来拼出 $I$ 的节点都完整落在某一块内，按块分组就得到每一块的覆盖。反过来，各块两两无交，拼起来恰好是 $I$。

因此只需维护每个节点 $v$ 的需求次数 $c_v$，即有多少个当前目标的分解包含 $v$。只要 $c_v>0$，就必须能完整覆盖 $v$。不同目标可能共用一块，所以删除时要将次数减一。

### 状态设计

将本题的单个 DP 状态定义为 $(p,q)$，表示当前的最小空间和最优方案数。下文默认 $q$ 参与的运算都取模。

我们意识到，在线段树上，一个节点 $[l,r]$ 能被覆盖，当且仅当存储方案中包含这个区间，或者我们的存储方案能覆盖 $[l, \mathrm{mid}], [\mathrm{mid}+1,r]$。由此启发我们考虑如下状态设计，对于表示 $[l,r]$ 的线段树节点 $u$：

+ $f_u$ 表示满足子树内全部需求的状态。

+ $g_u$ 表示**钦定存储方案能覆盖 $[l,r]$ 这个区间时**满足子树内全部需求的状态。

### 转移

为了方便描述，定义单个状态的加法操作和取 $\min$ 操作如下：

$$
\begin{aligned}
(p_1,q_1)+(p_2,q_2)&=(p_1+p_2,\ q_1q_2) \\
(p,q)+1&=(p+1,\ q) \\
\min\{(p_1,q_1), (p_2,q_2)\}&=
\begin{cases}
(p_1,q_1), &p_1<p_2 \\
(p_2,q_2), &p_1>p_2 \\
(p_1,q_1+q_2) &p_1=p_2
\end{cases}
\end{aligned}
$$

这个 DP 显然是从下往上进行的。我们 DP 到线段树节点 $u$ 的时候，设它的左儿子为 $L$，右儿子为 $R$。有以下转移：

$$
\begin{aligned}
f_u&=\begin{cases} g_u, & c_u>0\\ f_L+f_R, & c_u=0\end{cases}\\
g_u&=\min\{\,f_L+f_R+1,\ g_L+g_R\,\}
\end{aligned}
$$

解释：求 $g_u$ 时，

+ 存储方案选 $u$ 这个区间：$f_L+f_R+1$，$u$ 已覆盖整段，严格子区间的需求仍由儿子满足。

+ 存储方案不选 $u$ 这个区间：$g_L+g_R$，要拼出整段，左右儿子都必须能被完整覆盖。

求 $f_u$ 时，所有需求都在严格子树内，满足 $u$ 能被覆盖对这些需求没有帮助。

边界，叶子的状态，有 $f_\text{leaf}=([c>0],1), g_\text{leaf}=(1,1)$，其中方括号是艾佛森括号。

最终的答案就是 $f_\text{root}$。 

### 在线维护

按普通线段树区间查询递归。遇到完全包含的节点就修改 $c_u$ 并停止下降，回溯时重算沿途的 $f_u,g_u$。

**总时间 $O(n+q \log n)$，空间 $O(n)$。**

### 各档部分分

| 子任务                   | 分值  | 思路                                                                                                                                                                         |
| --------------------- | ---:| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1．$n=1$               | 5   | 唯一的叶子有需求时输出 `1 1`，否则输出 `0 1`。                                                                                                                                              |
| 2．$n\le 8,\ q\le 100$ | 7   | 最多有 $15$ 个树节点，枚举所有存储方案 $P$。把选中的 $[a,b]$ 看成有向边 $a\to b+1$，则 $[l,r]$ 可覆盖等价于 $l$ 能到达 $r+1$。预处理每个 $P$ 能覆盖的区间位集，每次扫描所有 $P$ 取最优。                                                 |
| 3．$nq\le 2\times10^6$ | 10  | 维护分解块的需求次数，每次操作后从叶到根重算整棵树的 DP，总时间 $O(nq)$。                                                                                                                                 |
| 4．只有单点                | 5   | 每个活动单点都强制选择对应叶子。设活动单点数为 $k$，答案为 $(k,1)$。                                                                                                                                   |
| 5．活动区间两两无交            | 8   | 所有分解块两两无交，每块至少要用一个节点，恰用一个时只能选该块本身。因此维护分解块总数即可，最优方案唯一。                                                                                                                      |
| 6．只有整段或单点             | 10  | 设有 $k$ 个活动单点。整段无需求或 $k=n$ 时，答案为 $(k,1)$。否则还须恰选一个节点，包含所有未激活叶子。用有序集合取最左、最右未激活叶子，设其最近公共祖先为 $u$，可选节点恰为 $u$ 及其祖先，答案为 $(k+1,\operatorname{depth}(u)+1)$，根深度为 $0$。$n=1$ 按第 1 档处理。 |
| 7．区间长度至多为 $2$         | 10  | 长度为 $2$ 的目标若不是树节点，就拆成两个叶子。每个双叶节点与其两个叶子构成独立小块，其余叶子单独成块。块内枚举至多 $2^3$ 种选法；只有父节点和恰好一个叶子有需求时，才有两种最优方案。维护各块最小空间之和及这类块的个数 $z$，方案数为 $2^z$。                                         |
| 8．只有加入                | 10  | 每个分解块只在首次被标记时更新祖先 DP。全树至多发生 $2n-1$ 次首次标记，加上区间分解，总时间 $O((n+q)\log(n+1))$。                                                                                                   |
| 9．操作区间均为树节点           | 10  | 每次只改变一个节点的需求标记，沿它到根的路径重算 DP，单次 $O(\log(n+1))$。                                                                                                                             |
| 10．无额外限制              | 25  | 使用完整算法，在一次区间递归中修改需求次数，并在回溯时合并两个状态。                                                                                                                                         |
