# 空间相同，方案不同 · v1

题面见 [statement.md](statement.md)。本题按子任务独立计分，组内全部通过才获得对应分数。

| 子任务 | 分值 | 测试点编号 |
| --- | ---: | --- |
| 1 | 5 | 1_1–1_3 |
| 2 | 7 | 2_1–2_5 |
| 3 | 10 | 3_1–3_5 |
| 4 | 5 | 4_1–4_3 |
| 5 | 8 | 5_1–5_3 |
| 6 | 10 | 6_1–6_4 |
| 7 | 10 | 7_1–7_4 |
| 8 | 10 | 8_1–8_4 |
| 9 | 10 | 9_1–9_4 |
| 10 | 25 | 10_1–10_8 |

文件名为 `子任务_组内编号.in` 和 `子任务_组内编号.ans`，组内从 1 开始，例如 `data/3_1.in` 和 `data/3_1.ans`。[cases.json](cases.json) 保存分组、规模、生成模式和种子。

每个子任务另有一组便于下发的示例，保存在 `samples/storage1.in`、`samples/storage1.ans` 至 `samples/storage10.in`、`samples/storage10.ans`。输入首行的 `Tid` 是对应的子任务编号。`storage3` 取 $n=100000,q=20$，达到该组 $nq$ 上限；`storage4` 至 `storage10` 均取 $n=100000,q=300000$，并遵守各自子任务限制。

- `std/std.cpp` 是完整正解。`std/partial_*.cpp` 包含小规模枚举、全树重算、互不相交、整段或单点、短区间五份部分分解。
- `wrong/` 包含七份可独立编译的错解，分别检验方案计数、引用次数、平局、树的分割规则、整数溢出及空集等边界。
- `gen.cpp` 和 `val.cpp` 使用随包附带的 `testlib.h`。生成器接收 `--tid`、`--n`、`--q`、`--mode`、`--seed`，并输出 `Tid n q` 首行；校验器从标准输入读取数据并接收 `--subtask=1` 至 `--subtask=10`，默认按完整数据范围检查。

在题目目录执行：

```sh
python3 genall.py
```

脚本需要 C++17 编译器和 Python 3.8 或更新版本。可传入 `--data-dir` 指定输出目录，或用 `--cxx` 指定编译器。所有数据通过验证后才写入目标目录。脚本会校验题面样例，对正式数据独立重算快照，并在适用时用部分分解逐行核验。七份错解均须在正式数据中产生错误输出。检查明细见 [verify/results.json](verify/results.json)。
