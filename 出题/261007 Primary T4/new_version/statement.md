# T4 小可可的信号接力

## 题目背景

月面基地由两排信号中继器组成。小可可正在检修这张信号网，想关闭一些暂时用不到的中继器。

## 题目描述

信号网可以看作一个有 $2$ 行、$n$ 列的方格。每个格子代表一个中继器：`.` 表示中继器正在工作，`#` 表示中继器已经关闭。

基地指挥舱连接着左上角的中继器，远端观测站连接着右下角的中继器。一条有效的信号路线必须从左上角出发，到达右下角；路线经过的中继器都必须正在工作，并且相邻的两个中继器必须位于共边的格子中。

小可可可以关闭一些正在工作的中继器。关闭后，指挥舱和观测站之间仍然必须存在至少一条有效的信号路线。请计算她最多可以新关闭多少个中继器。原本已经关闭的中继器不计入答案。

## 输入格式

第一行一个整数 $n$，表示信号网的列数。

接下来两行，每行一个长度为 $n$ 的字符串，表示一行中继器。`.` 表示工作，`#` 表示关闭。

## 输出格式

输出一个整数，表示最多可以新关闭的中继器数。

## 样例1

### 输入

```text
7
.......
....##.
```

### 输出

```text
4
```

### 解释

共有 $12$ 个工作的中继器。从左上角到右下角的路线至少要向右走 $6$ 步并向下走 $1$ 步，因此至少经过 $8$ 个中继器。保留其中一条最短路线，关闭其他工作中继器，最多可以关闭 $12-8=4$ 个。

## 样例2

输入文件见 `samples/path2.in`，对应输出见 `samples/path2.ans`。本样例中 $n=2000$。

## 样例3

输入文件见 `samples/path3.in`，对应输出见 `samples/path3.ans`。本样例中 $n=200000$。

## 数据范围与约定

- 指挥舱和观测站之间最初至少存在一条有效的信号路线。
- 只统计小可可新关闭的中继器。

对于 $20\%$ 的数据，$n\le 10$。

对于 $50\%$ 的数据，$n\le 2000$。

对于 $100\%$ 的数据，$1\le n\le 200000$。
