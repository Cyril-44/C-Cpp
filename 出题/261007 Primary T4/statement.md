# 路径保卫战

## 题目背景
小可可正在玩一个方格游戏。棋盘有两行、若干列，每个格子是白色或黑色。

## 题目描述
从最左边一列的某个白格出发，沿着白格移动到最右边一列的某个白格，就得到一条“从左到右的白色道路”。每一步只能走到上下左右相邻的格子。

小可可以把一些白格涂成黑色，但涂完后，棋盘上仍然必须存在至少一条从左到右的白色道路。他希望涂黑尽可能多的格子。请计算最多能涂黑多少个格子。原本就是黑色的格子不计入答案。

## 输入格式
第一行一个整数 $n$，表示棋盘的列数。接下来两行，每行一个长度为 $n$ 的字符串，表示棋盘的一行。`.` 表示白格，`#` 表示黑格。

## 输出格式
输出一个整数，表示最多能新涂成黑色的格子数。

## 样例1

### 输入
```text
7
.......
....###
```

### 输出
```text
4
```

### 解释
棋盘一共有 $11$ 个白格。第一行的 $7$ 个白格可以从左连到右，任何从左到右的道路至少要经过 $7$ 列，因此最短道路经过 $7$ 个格子。最多可以涂黑 $11-7=4$ 个格子。

## 样例2

输入文件见 `samples/path2.in`，对应输出见 `samples/path2.ans`。本样例中 $n=2000$。

## 样例3

输入文件见 `samples/path3.in`，对应输出见 `samples/path3.ans`。本样例中 $n=200000$。

## 数据范围与约定
- 棋盘最初至少存在一条从左到右的白色道路。
- 只统计小可可新涂黑的格子。

对于 $20\%$ 的数据，$n\le 10$。

对于 $50\%$ 的数据，$n\le 2000$。

对于 $100\%$ 的数据，$1\le n\le 200000$。
