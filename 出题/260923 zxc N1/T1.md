# 矩形

时间限制 $\text{1 s}$

空间限制 $\text{512 MB}$

## 题目描述

我们给你 $n$ 个矩形，第 $i$ 个矩形的左下角坐标为 $(xa_i,ya_i)$，右上角坐标为 $(xb_i,yb_i)$。

$q$ 次操作，操作有以下两种类型：

+ `Q l r` 代表求 $[l,r]$ 号矩形是否两两有公共点。

+ `C l r x y` 代表将 $[l,r]$ 号矩形 $x$ 坐标对应变化 $x$，$y$ 坐标对应变化 $y$。注意，不保证 $x,y$ 为正数。

## 输入格式

第一行两个数 $n,q$。

后面 $n$ 行每行四个数，分别是 $xa_i,ya_i,xb_i,yb_i$。

接着 $q$ 行，每行描述一个操作。

## 输出格式

对于每组 `Q` 操作，如果两两有交点输出 ``Yes``，否则输出`No`。

## 输入输出样例 #1

### 输入 #1

```
3 6
0 0 2 2
1 1 3 3
4 4 5 5
Q 1 2
Q 1 3
C 3 3 -3 -3
Q 1 3
C 2 2 10 0
Q 1 3
```

### 输出 #1

```
Yes
No
Yes
No
```

## 说明/提示

本题捆绑测试。

| Subtask | 特殊性质                 | 分值   |
|:-------:|:--------------------:|:----:|
| $1$     | $1 \le n,q \le 100$  | $5$  |
| $2$     | $1 \le n,q \le 3000$ | $25$ |
| $3$     | 保证没有修改操作             | $20$ |
| $4$     | $1 \le n,q \le 10^5$ | $30$ |
| $5$     | 无特殊性质                | $20$ |

对于 $100\%$ 的数据，$1 \le n,q \le 5 \times 10^5,-10^{10} \le xa_i,xb_i,ya_i,yb_i,x,y \le 10^{10}$。保证所有输入均为整数。

### 对于样例 $2 \sim 6$

样例 $2 \sim 6$ 依次满足 Subtask $1 \sim 5$ 的要求。
