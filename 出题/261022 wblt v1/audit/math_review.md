# 独立数学与暴力审查

审查结论：在所有运算取模 998244353、非正下标补零、越过 n 的差分修正忽略的约定下，题面操作唯一，二阶差分的周期延拓、右边界修正、仿射的四处修正与三个矩的重建公式均正确。

## 题意与唯一性

记窗口和为 W_s=sum(a_s,...,a_{s+k-1})，s=l,...,r-k+1。条件是每次操作自己的窗口二阶差分为常数，等价于所有存在的窗口三阶差分为零。

保留的 k+2 项恰好确定 W_l、W_(l+1)、W_(l+2)。令 B=W_(l+1)-W_l、C=W_(l+2)-2W_(l+1)+W_l，则

    W_(l+t) = W_l + t B + t(t-1)/2 C。

每个后续窗口恰有一个新加入的未知元素，其系数是 1，故由“目标窗口和减去其余已知 k-1 项”可逐项求得全部元素。这直接证明存在性与唯一性，不依赖差分周期。

- k=1 时，窗口和就是原序列，校准后区间是二次序列。
- r-l+1=k+2 时只有三个窗口，区间全被保留，操作恒等。
- n<3 时没有合法操作一；单点区间只会用于操作二、三。
- C 可以为零，也可以随操作变化，不另指定全局曲率。

## 周期范围的独立推导

由 W_(s+1)-W_s=a_(s+k)-a_s，再作两次差分，有

    W_(s+3)-3W_(s+2)+3W_(s+1)-W_s
      = (a_(s+k+2)-2a_(s+k+1)+a_(s+k))
        -(a_(s+2)-2a_(s+1)+a_s)
      = e_(s+k+2)-e_(s+2)。

合法 s 范围为 l<=s<=r-k-2，故 e_i=e_(i-k) 的约束恰覆盖 i=l+k+2,...,r。种子是 e_(l+2),...,e_(l+k+1)，目标段是 e_(l+2),...,e_r，长度 L=r-l-1。不能从 l 或 l+1 开始重复。

## 操作一的边界

设目标段从 0 开始的变化为 delta_j，dS=sum(delta_j)，dT=sum(j delta_j)。二次积分给出

    delta a_r = sum((L-j)delta_j) = L dS-dT = dA，
    delta(a_r-a_(r-1)) = dS，
    delta a_(r-1) = dA-dS。

区间外原数组应保持不变，所以直接代入 e 的定义得到

    delta e_(r+1) = -2dA+(dA-dS) = -dA-dS，
    delta e_(r+2) = dA。

两项修正还使总差分变化及其一阶矩变化在右端外抵消，后续元素全部恢复原值。r=n-1 时只保存第一项修正，r=n 时均忽略。dT 必须用目标段的局部 0 基下标；若改用全局下标，dA 公式也必须随之调整。

## 操作二与修正重合

统一写原数组变化 delta a_i=((u-1)a_i+v) * [l<=i<=r]。目标差分变化直接为 delta a_i-2delta a_(i-1)+delta a_(i-2)。把它与先执行 e_[l..r]*=u 的变化相减，得到：

    e_l     += (u-1)(2a_(l-1)-a_(l-2))+v，
    e_(l+1) -= (u-1)a_(l-1)+v，
    e_(r+1) -= (u-1)(2a_r-a_(r-1))+v，
    e_(r+2) += (u-1)a_r+v。

这里所有 a 都是同一旧版本的值。对于 l=r，中间两项都落到 e_(l+1)，相加后等于 -2((u-1)a_l+v)，正好是单点变化对下一项二阶差分的影响。不能覆盖重合修正。u=0 合法，算法不得使用 u 的逆元。左端取 a_0=a_(-1)=0；右端仍忽略越界位置。

## 矩与整数范围

对前缀长度 t，以 j=i-1 为 0 基下标：

    a_t = sum((t-j)e_(j+1)) = t M0-M1，
    F(t) = sum(C(t-j+1,2)e_(j+1))
         = C(t+1,2)M0-t M1+M2。

第二式使用 C(t-j+1,2)=C(t+1,2)-tj+C(j,2)。拼接长度 h 的左段和右段时，C(h+j,2)=C(h,2)+hj+C(j,2)，因此右段矩平移为 (R0,R1+hR0,R2+hR1+C(h,2)R0)。区间乘法把三个矩同时乘以该因子。

二次序列的唯一性只依赖系数 1 的递推。闭式中的 1/2 在奇素数域中存在，也可先在整数域算 t(t-1)/2 再取模。n<=3,000,000 时三角数与两个模数剩余类之积都能放入有符号 64 位整数；先连乘三个未约简因子可能溢出，应在乘积间取模。下标、树权重、长度、引用计数不是模数域元素。

## 独立实现与已完成验证

- `solutions/brute.cpp` 直接递推窗口和及其一次差分，再用滑出元素求新元素；不构造 e，也不使用周期性质。时间 O(nm)，空间 O(n)。
- `tools/oracle_fuzz.py` 的答案 oracle 使用前三窗口的闭式公式，直接重算已知 k-1 项；不复用 C++ 暴力的滑动窗口递推。
- 数学自检将 n=3..5、初值来自 {0,1,P-1} 的所有合法操作一全部枚举，共 2,781 组，并完成 10,000 组随机公式审查；每次都核对直接题意数组、差分更新、窗口三阶差分以及每个前缀的点值/区间和矩公式。
- 随机对拍种子 20261021，n<=80，基础操作数<=240：5,010 个用例（10 个固定边界用例及 5,000 个随机用例），共 2,530,586 次操作、2,047,716 个查询答案，Python oracle、C++ brute 和启用 `AUDIT` 的标准解全部一致。标准解同时在每次操作后检查共享图入度、引用计数、回收池、矩和逻辑权重平衡，未发现异常。运行 104.410 秒。
- `samples/01.in`、`02.in`、`03.in` 已用 C++ 暴力独立核对，全部一致。

可复现命令（从项目工作目录执行；Windows 下先把编译器运行库目录加入 PATH）：

```text
python outputs/window-calibration/tools/oracle_fuzz.py --self-check-only --self-check 10000
python outputs/window-calibration/tools/oracle_fuzz.py --std work/bin/std_audit.exe --brute work/bin/brute.exe --cases 5000 --n-max 80 --m-max 240 --seed 20261021 --self-check 0 --progress-every 1000
```

对拍失败时工具自动保存完整输入、期望输出、实际输出、stderr、主种子与重放参数。可用 `--input` 重放原输入，或用 `--case-seed` 直接重放独立随机用例种子。


## 独立满分参考的补充核对

`solutions/reference_avl.cpp` 直接保存原数组。它从 $a_{l+1},\ldots,a_{l+k}$ 取种子，令 $C=(a_{l+k+1}-a_{l+k})-(a_{l+1}-a_l)$、$D=a_{l+k+1}-a_{l+1}$，相对下标满足 $A(j+k)=A(j)+Cj+D$。跳过 $q$ 块的增量为 $qCj+qD+Ck\binom q2$，可通过局部一次位置标记倍增。该实现不复用 WBLT 的二阶差分、矩或边界修正。

种子 726118612 的 3010 个小用例通过独立 oracle 与两个结构审计；随后两个执行环境各自对全部 40 个正式点进行 WBLT/AVL 交叉核对，全部一致。完整原始记录及程序化验题的范围见 `reference_validation.json`、`full_verification_windows.json`、`full_verification_linux.json` 和题包 `report.md`。
