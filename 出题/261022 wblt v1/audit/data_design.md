# 数据分组、构造与校验约定

## 计分分组

模数为 `P=998244353`。当前全局限制为 `1<=n,m<=3000000`，最终时空限制由主流程实测确定。分组常数集中记录在 `config/scoring.json`：`small_max=2000`，`medium_max=20000`。各组独立、组内全部测试通过才获得该组全部分数，总分 100，不设组间依赖。

| 组 | 分数 | 互斥条件 | 主要覆盖算法 |
| --- | ---: | --- | --- |
| 1 | 20 | `max(n,m)<=2000` | 直接维护原序列的小规模暴力 |
| 2 | 15 | `max(n,m)>2000`，不存在操作 1 | 仿射修改与求和线段树 |
| 3 | 15 | `max(n,m)>2000`，存在操作 1，且全部操作 1 的 `k=1` | 二次多项式赋值与仿射修改 |
| 4 | 20 | `2000<max(n,m)<=20000`，存在 `k>1` 的操作 1 | 一般操作的中规模部分分 |
| 5 | 30 | `max(n,m)>20000`，存在 `k>1` 的操作 1 | 满规模算法 |

判组顺序为：先判小规模，再判无操作 1，再判全部 `k=1`，最后按 20000 分中、大规模。这五组互斥且覆盖全部合法输入。不存在操作 1 的小规模输入仍属于组 1。组 4/5 的首个操作固定为 `1 1 4 2`，组 3 的首个操作固定为 `1 1 3 1`，均为最短无效校准，保留随机初值而认证组别。最后一个操作固定为 `3 1 n`；因此各组的存在性条件及至少一次查询无需依赖随机概率。

分组仅描述测试数据的保证。部分分算法可以同时通过若干组，其总得分为这些组分数之和。组 4 是否能让不回收历史结点的实现通过，应由最终内存、时间实测核实，不能仅凭分组上界保证。

## 文件与可复现性

- `config/data_spec.json`：40 个正式测试点的清单，每点包含唯一编号、所属组、`n,m`、固定种子、初值类型、操作策略与中文用途。
- `tools/generate.py`：Python 3 标准库生成器；不依赖第三方包，不生成答案。
- `tools/validator.cpp`：独立 C++17 校验器，不依赖 testlib。

五组分别为 8、6、7、8、11 点。组 5 中仅 `g5_full_mixed` 与 `g5_full_gc` 同时取 `n=m=3000000`；其余点采用一维较大，或约 30 万至 100 万规模，避免全部测试都达到两维上限。`N_MAX`、`M_MAX` 是由 `scoring.json` 解析的符号尺寸；其余尺寸是清单中明确记录的整数。

每点种子是显式整数。初值随机数与操作随机数分别使用 `seed xor 0xA0761D6478BD642F` 和 `seed xor 0xE7037ED1A0B428DB` 初始化独立的 `random.Random`。生成器不使用时间、系统熵、Python 的随机哈希或集合遍历次序来决定数据。同一份生成器、规格、参数及 Python 运行时重复生成可得到字节完全一致的输入。

数组每批输出 8192 个数，操作每批输出 8192 行；不保存整个数组或整个操作序列，也不执行这些操作。因此辅助内存与全局 `n,m` 无关。`sweep` 策略只用于 `n=9` 的小点，其循环枚举缓存至多 84 个 `(l,r,k)` 三元组。

以目录方式生成时写入 `generation_manifest.json`，记录解析后的尺寸、每点种子与用途、Python 版本、生成器源码及原始规格的 SHA-256。生成器未指定选择器时只列出清单，不会默认产生全部大数据。

## 构造策略

初值包括随机模数值、反复出现 `0,1,P-1,P-2,P/2,2` 的边界值、短周期数组以及二次多项式数组。策略之间交叉使用这些初值，避免仅靠某种初值识别数据。

1. **小边界与退化周期。** 单独设置 `n=1,3,4`；校准长度 3 和 4；选择 `k=1`、`k=len-2`、`k=len-3`。`k=len-2` 恰好保留整个区间，必须不改变值；`k=len-3` 只改变一个值。查询、仿射也覆盖单点、前后缀、`r=n` 和 `r=n-1`。
2. **小规模枚举与随机。** `g1_sweep` 周期枚举 `n=9` 的全部合法 `(l,r,k)`，中间穿插仿射和查询，供独立暴力检查。另有小规模一般随机点与组边界 `2000/2001`。
3. **仿射复合。** 各修改策略按独立仿射计数循环选用 `u=0,1,P-1`，包含 `(u,v)=(1,0),(0,0),(P-1,P-1),(1,P-1),(P-1,1)`，同时保留随机 `u,v`。独立计数避免某种操作调度遗漏特定乘数。
4. **不同偏移与非整周期尾部。** `offset` 在长区间上不断改变起点，周期从素数、2 幂及其前后相邻数中选择。覆盖相同周期的不同对齐方式与不能恰好整除的尾部。
5. **共享、嵌套与仿射。** `nested` 反复使用交错前后缀，`gc` 在前后缀、内部区间之间反复校准并穿插仿射和查询，迫使结构维护共享引用、旧尾部以及惰性标记。`gc` 的每 16 步通常为 12 次校准、3 次仿射、1 次查询。
6. **小 k 与随机大 k。** `small_k` 使用 `1,2,3,4,5,7,8,15,16,17,...,1023,1024,1025`，并截断到合法上界。`large_k` 从区间合法上界的四分之一至上界均匀取值，且仍混入 `1,len-2,len-3`。
7. **长度分界。** 包含 `16383/16384/16385` 和 `1048575/1048576/1048577`，以及 `1999,19997,999983` 等素数附近的长度。该设计同时关注非平衡切分、非整周期尾段及不恰好对齐的查询。
8. **无效校准。** `noop` 初值为 `a_i=A i²+B i+C (mod P)`，仿射始终作用于整个数组，故任何长度 k 的窗口和都是关于窗口起点的二次多项式。其二阶差分恒定，保留前 `k+2` 项后校准应得到原数组；清零与取负也保持该性质。此组同时检查大量历史操作是否导致空间随 m 增长。
9. **长期保留大随机种子。** `g5_preserved_seed` 令 `H=floor(n/2)`，前半区 `[1,H]` 从不被改变。每次校准选 `k` 约在 `[n/3,n/2]`，起点取 `l=H-k-1`，使保留的前 `k+2` 项恰好结束于 H，校准只覆盖后半区；仿射也仅修改后半区。交替改变周期、末尾截断以及尾部局部仿射，避免全局短周期清空导致随机初值被立即压缩，重点针对深拷贝、显式展开与不回收实现。

这些构造覆盖了目标错误模式，不将“某策略名字出现”视为足够证据：集成时应统计操作类型、退化 k、仿射特殊参数，并用独立暴力检查组 1 和缩小规模的各策略。最终大点需在标准解、目标部分分与错误实现上实测后确认。

## 使用

在题包根目录执行：

```text
python tools/generate.py --list
python tools/generate.py --json
python tools/generate.py --case g1_sweep --output ../../work/data-tools/g1_sweep.in
python tools/generate.py --group 4 --output-dir ../../work/data-tools/group4
python tools/generate.py --all --output-dir data
g++ -std=c++17 -O2 -Wall -Wextra tools/validator.cpp -o validator
validator --group 4 --max 3000000 < data/g4_random.in
```

`--case` 可重复指定，多个测试点必须指定 `--output-dir`。支持 `--spec`、`--scoring` 切换规格文件。`--max` 覆盖全局 n,m 上限及符号尺寸；若所选测试点的固定尺寸超出新上限则明确报错，不悄悄裁剪导致构造用途失真。

命令示例中的重定向适用于常见 POSIX/cmd shell；Windows PowerShell 可由 Python `subprocess.run(..., stdin=open(...,'rb'))` 调用，避免文本管道改变换行或编码。

校验器默认检查全局合法性并打印实际所属组；正式校验必须传入 `--group G --max X`。也可用 `--max-n`、`--max-m` 分别指定两维上限，用 `--small-max`、`--medium-max` 改变判组界限。以上参数只作用于校验器，配置文件不会自动修改 C++ 编译常数。若最终修改组界限，应同步 `scoring.json`、规格、题面及调用参数。

## 严格格式与边界

输入必须依次为：一行 n、一行恰好 n 个初值、一行 m、恰好 m 行操作。各行数字之间恰好一个 ASCII 空格，不允许前后空格、制表符、空行、BOM、正负号或额外字段；接受 LF 与 CRLF，每行（包括末行）必须有换行，最后一行后不允许额外字节。十进制整数允许前导零。生成器始终输出 ASCII、LF、无前导零。

校验器逐字符流式读取，以范围上界逐位检查整数，拒绝溢出。检查初值、`u,v` 均在 `[0,P)`，操作类型在 `{1,2,3}`，`1<=l<=r<=n`；对操作 1 另检查长度至少 3 与 `1<=k<=r-l-1`。操作总数准确，至少有一次操作 3。最后按互斥条件核实分组，拒绝把无操作 1 或全部 `k=1` 的输入标成组 4/5。退出码：0 合法，1 输入非法，2 命令行参数非法。
