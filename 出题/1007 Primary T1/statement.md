# 小可可的餐巾纸

小可可家里有一盒餐巾纸，一共 $300$ 张。每张餐巾纸都叠着两层。

一天，小可可在卧室中用掉了一些餐巾纸的**纸层**，一共用掉了 $x$ **层**；厕所里也用掉了 $y$ 张餐巾纸。现在小可可想知道，盒子里还剩多少张完整的餐巾纸。

你能帮小可可算一算吗？

## 输入格式

一行两个整数 $x$ 和 $y$，中间用空格隔开。

- $x$ 表示卧室用掉的纸层数。
- $y$ 表示厕所用掉的餐巾纸张数。

## 输出格式

输出一个整数，表示剩下的完整餐巾纸张数。

## 样例 1

### 输入

```text
8 5
```

### 输出

```text
291
```

### 样例说明

每张餐巾纸有两层，卧室用掉的 $8$ 层正好是 $4$ 张餐巾纸。再减去厕所用掉的 $5$ 张，最后还剩 $291$ 张。

## 样例 2

满足特殊性质 $x=0$ 的样例，见 `tissue2.in` 和 `tissue2.ans`。

## 样例 3

较大的边界样例（$x=598$，$y=0$），见 `tissue3.in` 和 `tissue3.ans`。

## 数据范围

保证 $x$ 是非负**偶数**，$0 \le x \le 598$，$0 \le y \le 299$，并且没有把餐巾纸全部用完，即

$$
\frac{x}{2} + y < 300.
$$

- 对于 $30\%$ 的数据，保证 $x=0$。
- 对于 $70\%$ 的数据，没有额外限制。
