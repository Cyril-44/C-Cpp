# 上下左右(lrud)

时间限制：1 秒。空间限制：512 MiB

## 题目描述

给定正整数 $N$。

有一个 $N \times N$ 的网格。从上往下数第 $r$ 行、从左往右数第 $c$ 列的格子记作 $(r, c)$。

初始时，棋子放置在格子 $(1, 1)$ 上。

你需要恰好执行 $N^2 - 1$ 次以下操作，使得棋子最终停在格子 $(N, N)$ 上：

- 将棋子移动到当前所在格子的上下左右**或斜向**相邻格子之一。

并且，在整个移动过程中，$N^2$ 个格子必须恰好各访问一次。初始放置棋子的格子 $(1, 1)$ 视为已被访问。

请计算一个操作序列中棋子恰好向右（不包括右上，右下）移动次数的最大值，并给出一组操作序列。

你需要解决 $T$ 组这样的问题。

## 输入格式

第一行一个整数 $T$，表示数据组数。

之后 $T$ 行，每行一个整数 $N$。

## 输出格式

对于每组数据，一行输出一个整数，表示向右移动次数的最大值；然后一行一个字符串表示操作序列，第 $i$ 个字符表示路径中第 $i$ 步的移动方向。其中，`Q`，`W`，`E`，`D`，`C`，`X`，`Z`，`A`分别代表左上，上，右上，右，右下，下，左下，左。

## 样例 1

### 输入

```
3
2
3
4
```

### 输出

```
2
DZD
4
DDXAAXDD
8
DDDXZDQZQDZXDDD
```

## 数据规模与约定

所有数据均满足 $1\le T\le5$、$2\le N\le1000$。

本题采用分组计分。一个子任务内全部测试点通过后，才能获得该组分数；各组分数独立相加。

| 子任务 | 分值 | 额外限制 |
| --- | ---: | --- |
| 1 | 10 | $N\le3$ |
| 2 | 15 | $N\le4$ |
| 3 | 20 | 每组数据满足 $N\le4$ 或 $N$ 为奇数 |
| 4 | 20 | 每组数据满足 $N\le4$ 或 $N\not\equiv0\pmod4$ |
| 5 | 35 | 无额外限制 |

本题使用特殊评测。只要输出的路径合法且向右移动次数达到最大值，即可通过；操作序列不必与样例或标准答案相同。
