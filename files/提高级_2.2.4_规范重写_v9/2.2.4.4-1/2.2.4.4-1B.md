#### 代码示例

```cpp
/*
函数 mergeSort 可完成对数组指定闭区间内元素的归并排序
a：待排序数组，下标从 1 开始
temp：存放合并结果的临时数组
l、r：当前待排序区间的左右端点
*/

int a[MAXN], temp[MAXN];

void mergeSort(int l, int r){
    if (l >= r) return;

    // 先分别排好左右两个闭区间
    int mid = l + (r - l) / 2;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);

    // 双指针合并；相等时取左段以保持稳定性
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r){
        if (a[i] <= a[j]){
            temp[k++] = a[i++];
        } else {
            temp[k++] = a[j++];
        }
    }
    while (i <= mid) temp[k++] = a[i++];
    while (j <= r) temp[k++] = a[j++];

    // 将合并结果复制回原数组
    for (int i = l; i <= r; i++) a[i] = temp[i];
}
```
