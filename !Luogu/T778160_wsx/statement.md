## 题目描述

给你一个长度为 $n$ 的序列 $a$ 和一个 $k$，我们认为一个区间为好的，当且仅当其所有元素和不小于 $0$，且其长度不小于 $k$。我们认为一个极好子区间为除了本身不包含任何好区间的好区间，我们现在想要求的是，序列 $a$ 中极好子区间的个数。

## 输入格式

第一行 $n,k$ 代表序列长度和 $k$。

第二行 $n$ 个数描述一个序列。

## 输出格式

一个数，代表问题的答案。

## 输入输出样例 #1

### 输入 #1

```
5 3
1 4 -14 7 3
```

### 输出 #1

```
1
```

## 说明/提示

| 测试点编号  | $n$  | 特殊性质  |
|:-:|:-:|:-:|
| $1 \sim 3$  | $\le 100$  | 无  |
| $4 \sim 8$  | $\le 5000$  | 无  |
| $9 \sim 12$  | $\le 10^6$  | $a_i > 0$  |
| $13 \sim 15$  | $\le 10^6$  | 最多有 $10$ 个数满足 $a_i < 0$  |
| $16 \sim 18$  | $\le 10^6$  | $-100< a_i < 100$  |
| $19 \sim 20$  | $\le 10^6$  | 无  |

对于 $100\%$ 的数据，$1 \le n \le 10^6,-10^9 \le a_i \le 10^9$。
