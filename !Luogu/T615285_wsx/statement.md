## 题目背景

这是个属于每个人的梦，希望大家都可以有一个完美的结束。

## 题目描述

设函数 $f(n)$ 表示满足 $1\le a\le b \le n$ 且 $\dfrac{\text{lcm}(a,b)}{\gcd(a,b)}=a$ 的正整数数对 $(a,b)$ 的个数。

共 $q$ 个询问，每次询问给定 $l,r$，询问 $\sum\limits_{n=l}^rf(n)$，请将答案对 $10^9+7$ 取模。

## 输入格式

共 $q+1$ 行，第 $1$ 行一个正整数 $q$，表示询问次数。

第 $2$ 到 $q+1$ 行，每行两个正整数 $l,r$，表示查询给定的参数。

## 输出格式

共 $q$ 行，一行一个正整数，表示答案对 $10^9+7$ 取模后的值。

## 输入输出样例 #1

### 输入 #1

```
4
1 4
5 14
19 198
114514 1919810
```

### 输出 #1

```
5
32
6024
165262440
```

## 说明/提示

对于 $20\%$ 的数据，满足 $1\le q\le5$，$1\le l\le r\le300$。

对于 $50\%$ 的数据，满足 $1\le q \le 2\times10^5$，$1\le l\le r\le 10^9$。

对于 $100\%$ 的数据，满足 $1\le q \le 2\times10^5$，$1\le l\le r\le 10^{14}$。
