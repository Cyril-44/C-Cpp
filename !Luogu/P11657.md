$$
\global\def\ngt{{n_\texttt{)}}}
\global\def\nlt{{n_\texttt{(}}}
$$

本题直接用最基础的线段树结构维护即可。  
同时你可能需要了解部分 [楼房重建](https://www.luogu.com.cn/problem/P4198) 中的单边递归线段树思想。

我们不考虑括号序列的任何性质，也不把括号序列当作前缀和数组看。我们从括号序列的构造方式来考虑。容易发现，括号序列总是由 $AB$ 或者 $\texttt{(}A\texttt{)}$ 构成的，其中 $A,B$ 都是合法的括号序列。  
有了这个递归定义之后我们直接回到线段树，考虑维护左右信息的合并。  
首先我们考虑拼接的时候决定是否合法的核心刻画。如果我们从中间点向左边扫描，维护左括号减右括号的差值，同理向右边扫描维护右括号减左括号的差值。显然有效位置对 $(p,q)$ 等价于 ${n_l}_p={n_r}_q \ge 0$ 且左边的右括号一定匹配，右边的左括号一定匹配。  
发现在两边**满足除取等外的条件**的点值是单调不减的。于是我们考虑记录两边扫描过程中差值的极值。然后我们得到一个显然的贪心，就是拿极值更小的那一边，去另外一边去找到最远的匹配位置。这实际上由边界的单调性决定：随着匹配数量增加，可选择的最优左侧起点不会右移，最优右侧终点不会左移，因此跨区间长度不会减小。

受以上思维的引导，我们此时就可以完整地设计出来一个区间的信息：$(\nlt, \ngt, ans)$ 表示区间能提供的多余左括号的量、多余右括号的量和最长括号序列长度。  
$$
\emph{promote}(\emph{l, r})\emph{:} \\
\begin{aligned} \nlt &= \max(\nlt_l - \ngt_r, \; 0) + \nlt_r \\ \ngt &= \max(\ngt_r - \nlt_l, \; 0) + \ngt_l \\ ans &= \max(ans_l, \; ans_r, \; rp - lp + 1) \end{aligned}
$$
接下来我们需要计算位置 $lp$ 和 $rp$。  
为了方便，下文记 $k = \min(\nlt_l, \ngt_r)$。  
我们刚刚说“到另外一边去找最远匹配位置。”即找最远的位置 $p$，满足扫描到 $p$ 时的 $n_p = k$。  
考虑怎么接入线段树二分。发现直接二分会出问题，需要进行一些分讨。  
注意：我们目前讨论的 $\emph{promote}$ 并不等于 $\emph{pushup}$，所以线段树二分需要先把整区间拎出来，再进入对应的整区间进行二分。

![](https://cdn.luogu.com.cn/upload/image_hosting/1v8beln9.webp)
*本图仅供直观理解合并与二分干了什么。图中并没有覆盖所有情况。  
图中的绿色数量代表 $\ngt$，红色数量代表 $\nlt$，黑色代表 $\ngt_r, \nlt_l$。*

+ 计算左侧起点 $lp$
    + $\nlt_l=k$：找到使左侧未匹配右括号数达到 $\ngt_l$ 的最早前缀终点，起点取其后一位。
    + $\nlt_l>k$：从右向左找到未匹配左括号数首次达到 $k+1$ 的位置，起点取其后一位。
+ 计算右侧终点 $rp$
    + $\ngt_r=k$：找到从右向左扫描时未匹配左括号数达到 $\nlt_r$ 的位置，终点取其前一位。
    + $\ngt_r>k$：从左向右找到未匹配右括号数首次达到 $k+1$ 的位置，终点取其前一位。

$n_?>k$ 时具体的二分过程就是，如图中，以在 $r$ 中二分为例，我们先通过检查当前大区间以及前面是否提供足够的 $\texttt{)}$ 以定位到 $\text{II}$ 区间，同时也更新二分的数值，比如例子中查 $n_p \ge 5$，因为定位到 $\text{II}$，所以 $x \gets 4 = 5 - \ngt_\text{I} + \nlt_\text{I}$。然后每次二分查左边的有括号数量是否足够，是则进入左边，否则更新二分的数值 $x \gets x - \ngt + \nlt$。直到二分区间长度变为 $1$，我们就得到了答案。事实上，图中最后的二分区间落在星号右边的那个区间，但是注意答案是前一格。  
这样做显然是对的，因为我们找的是跳到 $n_p=k+1$ 前的最后一个位置，注意到 $\Delta n \le 1$，所以一定有 $n_{\text{prev}_p}=k$。

$n_?=k$ 时，如图中，我们先从方法 2 考虑二分的过程：在 $\text{I, II, III}$ 中选择一个大区间进去线段树二分。但是我们发现，即使枚举到 $\text{III}$ 了，仍然没有足够多的 $\texttt{(}$。考虑换一种思考方式，可以发现，只需要拿最右边的多余 $\texttt{)}$ 的位置 $+1$，一定满足要求。图中的星号即为返回的答案。

于是左右合并，我们就弄完了。  
考虑这么多，无非就是为了区间查询的时候能够合并两个任意相邻区间。

现在再考虑维护区间翻转。可以容易地使用二倍空间维护翻转后的序列，并使用懒标记，这样区间翻转我们就做完了。

时间复杂度 $O(n + q \log^2 n)$，预处理是线性，查询 $\log^2$ 因为是单边递归和区间修查。

```cpp
constexpr int N = 4000005;
int n;
class SegTr {
    struct Node { // nl: 左括号（在后缀）最多剩多少，nr: 右括号（在前缀）
        int nl, nr, ans;
    } tr[N << 2], revtr[N << 2];
    bool inv[N << 2];
    void invert(int u) { inv[u] = !inv[u]; std::swap(tr[u], revtr[u]); }
    void pushdown(int u) { inv[u] && (invert(u<<1), invert(u<<1|1), inv[u] = false); }
    int pres(Node *tr, int L, int R, int x) { // 找到第一个满足 [L, p] 的 n_) = x 的 p
        if (x == 0) return L - 1;
        for (auto [u, l, r] : nodes) if (L <= l && r <= R) {
            if (tr[u].nr >= x) {
                while (l < r) {
                    int mid = l + r >> 1; pushdown(u);
                    if (tr[u<<1].nr >= x) r = mid, u = u<<1;
                    else x = x - tr[u<<1].nr + tr[u<<1].nl, l = mid+1, u = u<<1|1;
                }
                return l;
            }
            x = x - tr[u].nr + tr[u].nl;
        }
    }
    int sufs(Node *tr, int L, int R, int x) {
        if (x == 0) return R + 1;
        for (auto it = nodes.rbegin(); it != nodes.rend(); ++it) {
            auto [u, l, r] = *it;
            if (L > r || R < l) continue;
            if (tr[u].nl >= x) {
                while (l < r) {
                    int mid = l + r >> 1;
                    pushdown(u);
                    if (tr[u<<1|1].nl >= x) l = mid + 1, u = u<<1|1;
                    else x = x - tr[u<<1|1].nl + tr[u<<1|1].nr, r = mid, u = u<<1;
                }
                return l;
            }
            x = x - tr[u].nl + tr[u].nr;
        }
    }
    Node promote(const Node &ls, const Node &rs, int l, int r, int mid, Node *tr) {
        Node res = {
            std::max(ls.nl - rs.nr, 0) + rs.nl,
            std::max(rs.nr - ls.nl, 0) + ls.nr,
            std::max(ls.ans, rs.ans)
        };
        const int n = std::min(ls.nl, rs.nr);
        const int lp = ls.nl == n ? 
            pres(tr, l, mid, ls.nr) + 1 : 
            sufs(tr, l, mid, n+1) + 1;
        const int rp = rs.nr == n ? 
            sufs(tr, mid+1, r, rs.nl) - 1 :
            pres(tr, mid+1, r, n+1) - 1;
        res.ans = std::max(res.ans, rp - lp + 1);
        return res;
    }
    std::vector<std::tuple<int,int,int>> nodes;
    void loc(int u, int l, int r) {
        if (L <= l && r <= R) { nodes.emplace_back(u, l, r); return; }
        int mid = l + r >> 1;
        pushdown(u);
        if (L <= mid) loc(u<<1, l, mid);
        if (mid < R) loc(u<<1|1, mid+1, r);
    }
    void pushup(int u, int l, int r) {
        int mid = l + r >> 1;
        nodes = {{u<<1, l, mid}, {u<<1|1, mid+1, r}};
        tr[u] = promote(tr[u<<1], tr[u<<1|1], l, r, mid, tr);
        revtr[u] = promote(revtr[u<<1], revtr[u<<1|1], l, r, mid, revtr);
    }

    int L, R;
    void upd(int u, int l, int r) {
        if (L <= l && r <= R) return invert(u);
        int mid = l + r >> 1;
        pushdown(u);
        if (L <= mid) upd(u<<1, l, mid);
        if (mid < R) upd(u<<1|1, mid+1, r);
        pushup(u, l, r);
    }
public:
    void build(int u=1, int l=1, int r=n) {
        if (l == r) {
            tr[u] = {1, 0, 0}, revtr[u] = {0, 1, 0};
            bool flg; fin >> flg;
            if (flg) std::swap(tr[u], revtr[u]);
            return;
        }
        int mid = l + r >> 1;
        build(u<<1, l, mid), build(u<<1|1, mid+1, r);
        pushup(u, l, r);
    }
    void flip(int l, int r) { L=l, R=r; upd(1, 1, n); }
    int inquire(int ql, int qr) {
        L=ql, R=qr, nodes.clear(); loc(1, 1, n);
        bool first = true; Node res;
        for (auto [u, l, r] : nodes) {
            if (first) res = tr[u], first = false;
            else res = promote(res, tr[u], ql, r, l-1, tr);
        }
        return res.ans;
    }
} f;
```
